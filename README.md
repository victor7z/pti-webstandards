# Arte em Tons 🎨

Projeto acadêmico de uma página de apresentação de serviços de pintura, feito com HTML e CSS na faculdade Senac (Web Standards).

## 🧩 O que a página tem

- Seção de serviços
- Seção de diferenciais
- Seção de contato, com a estrutura visual de um formulário

## 🛠️ Tecnologias

HTML · CSS

## 📂 Organização

- `index.html`: estrutura da página
- `estilos/`: arquivos de estilo

## ▶️ Como ver

Baixe o repositório e abra o arquivo `index.html` no navegador.
